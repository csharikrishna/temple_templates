## 🪔 The 4 Architectural Archetypes

### 1. Classical Ashram & Ceremonial Mandir (`templates/template_1/`)
* **Inspiration**: Traditional Hindu sanctum majesty, Ballarat Hindu Temple (BHTCC) Australian heritage, and Shirdi Sansthan.
* **Palette**: Deep Kumkum Crimson (`#58111A`), Royal Maroon (`#3C0A11`), Antique Temple Gold Foil (`#D4AF37`), Sandalwood Ivory (`#FAF7F2`).
* **Signature Layout**: Centered emblem header with Sanskrit shloka (*|| धर्मो रक्षति रक्षितः ||*); full-bleed ceremonial hero; floating 4-metric statistics ribbon; 16:9 Live Sanctum Altar with interactive Web Audio bell & Pushpa flower shower; 2-column bento box masterplan showcase; 2016–2026 historical spine.
* **Pages**: `index.html`, `project.html`, `worship.html`, `community.html`, `donate.html`.

### 2. Consumer DevTech Mobile-First App (`templates/template_2/`)
* **Inspiration**: Sri Mandir's high-conversion D2C devotional ecosystem.
* **Palette**: Auspicious Sacred Saffron (`#D9480F`), Terracotta (`#9A3412`), Marigold Gold (`#F59F00`), Sunset Amber (`#FAB005`), Warm Pearl (`#FFFDF9`).
* **Signature Layout**: Sticky mobile app navbar with in-header search; horizontal circular story bubbles tray (Book Pooja, Live 24/7, Remote Sankalp, Annadanam, Sponsor Brick, Yoga, Child Safe WWCC, Membership); 50/50 split cockpit hero with 1-click fast Gotra/Nakshatra booking form on left and 24/7 live prayer ticker on right.
* **Pages**: `index.html`, `project.html`, `worship.html`, `community.html`, `donate.html`.

### 3. Operations Command Center & Pilgrimage Hub (`templates/template_3/`)
* **Inspiration**: Tirumala Tirupati Devasthanams (TTD) and monumental granite stone temple engineering.
* **Palette**: Deep Obsidian Granite (`#111816`), Ancient Chiselled Bronze (`#C2845B`), Sacred Tulasi Emerald (`#0F5132`), Sandstone Mist (`#F8FAFC`).
* **Signature Layout**: Enterprise header with language toggles (English, Telugu, Hindi, Tamil) and SSL 256-bit security badge; emergency flash notification marquee; real-time pilgrim telemetry dashboard (Live queue waiting time, 24 of 75 parking bays, 1,240 pilgrims welcomed, 680 meals served); 1080p Moolasthanam live monitor; Special Entry Darshan (SED) priority pass generator; 3×3 Direct Online Services Matrix (`SRV-01` to `SRV-09`).
* **Pages**: `index.html`, `project.html`, `worship.html`, `community.html`, `donate.html`.

### 4. Grand Unified Temple Portal — Original Masterpiece (`templates/template_4/`)
* **Inspiration**: The monumental synthesis uniting BHTCC diaspora vision, Sri Mandir D2C pujas, TTD 8-tile pilgrim hub, and Shirdi live darshan.

* **Signature Layout**: Dual Hero (Vision narrative + Live Altar Player with Web Audio Bell synthesizer overtone), 8-tile Pilgrim Dashboard, filterable Puja catalog, live Brick crowdfunding meter, and interactive Sankalp booking modal.
* **Pages**: `index.html`, `pujas.html`, `darshan.html`, `project.html`, `donate.html`, `worship.html`.

## 🚀 GitHub Pages Deployment

1. Go to repository **Settings** → **Pages**.
2. Under **Build and deployment** → **Source**, select **Deploy from a branch**.
3. Select branch **`main`** and folder **`/ (root)`**.
4. Click **Save**.
5. Your temple website and switcher studio will be live at:
   `https://csharikrishna.github.io/TEMPLE_TEMPLATES/`
   and
   `https://csharikrishna.github.io/TEMPLE_TEMPLATES/switcher.html`
